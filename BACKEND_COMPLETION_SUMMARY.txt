              decrement_event_attendees

Issue 2: Orders Table Schema Mismatch
  - Problem: Schema had different column names than service expected
  - Expected: user_email, full_name, phone, city, order_notes,
              subtotal, delivery_fee
  - Schema had: delivery_name, delivery_phone, notes
  - Fixed: Created migration 005_fix_orders_schema.sql
  - Status: ✅ RESOLVED

Issue 3: Exam Type Enum Mismatch
  - Problem: Schema constraint vs service expectations inconsistent
  - Schema: ('midterms', 'final', 'resit')
  - Services: ('partiel', 'midterm', 'resit')
  - Fixed: Created migration 006_fix_exam_types.sql
  - Status: ✅ RESOLVED

Issue 4: Missing Favorites Table
  - Problem: Service complete but database table missing
  - Fixed: Created migration 007_create_favorites_table.sql
  - Includes: RLS policies, unique constraints, indexes
  - Status: ✅ RESOLVED
